# التقييم الإلكتروني

تطبيق ويب يعمل على الجوال والحاسب، يحسب قيمة العقار بطريقة **البيوع المقارنة** للأرض وطريقة **التكلفة** للمباني، بنفس معادلات ملف المقيّم المعتمد.

يشمل: حسابات مستخدمين، اعتماد من المدير، صلاحيات (إدخال / إدخال وتصدير)، رسوم بيانية، مرفقات إلكترونية، وبحث في التقييمات المحفوظة.

**الرابط المستهدف:** `https://etaqyeem.github.io`

---

## التشغيل — أربع خطوات

### ١. المستودع والنشر — مكتمل ✅

المنظمة `etaqyeem` والمستودع `etaqyeem.github.io` منشأان، والملفات مرفوعة، وGitHub Pages يعمل.
الرابط المباشر: **https://etaqyeem.github.io**

لتحديث أي ملف لاحقًا: **Add file → Upload files** ثم **Commit changes** — ويُنشر خلال دقيقتين.

### ٢. قاعدة البيانات (Supabase)

1. افتح [supabase.com](https://supabase.com) وسجّل الدخول بحساب Google.
2. **New project** → الاسم `taqyeem` → كلمة مرور لقاعدة البيانات (احفظها) → المنطقة **Frankfurt** أو **Ireland** → **Create**.
3. **SQL Editor → New query** → الصق محتوى `supabase-setup.sql` كاملًا → **Run** → يجب أن تظهر `Success`.

### ٣. ربط التطبيق بقاعدة البيانات

من **Project Settings → API** انسخ:

| في Supabase | ضعه في `config.js` |
|---|---|
| `Project URL` | `url` |
| `anon public` | `anonKey` |

ثم ارفع `config.js` المعدَّل إلى المستودع (Add file → Upload files، وسيستبدل القديم).

> **لا تنسخ مفتاح `service_role` أبدًا.** المفتاح العام `anon` آمن للظهور في المتصفح؛ الحماية الحقيقية في سياسات RLS التي شغّلتها في الخطوة السابقة.

### ٤. تعيين المدير الأول

1. افتح `https://etaqyeem.github.io` → **طلب حساب جديد** → سجّل باسمك وبريدك.
2. ارجع إلى Supabase → **SQL Editor** → شغّل بعد وضع بريدك:

   ```sql
   update public.profiles set role = 'admin' where email = 'بريدك@example.com';
   ```

3. حدّث صفحة التطبيق — سيفتح لك، ويظهر قسم **إدارة المستخدمين**.

من الآن: أي موظف يفتح الرابط ويطلب حسابًا، فيظهر طلبه عندك بنقطة برتقالية، وتختار له الصلاحية.

## إعدادات موصى بها في Supabase

**Authentication → Providers → Email**

- للاستخدام الداخلي: أغلق **Confirm email** ليدخل الموظف مباشرة بعد التسجيل (الاعتماد عندك على أي حال).

**Authentication → URL Configuration**

- ضع `https://etaqyeem.github.io` في `Site URL` ليعمل رابط استعادة كلمة المرور.

## المعادلات المطبَّقة

```
السعر بعد تسوية التمويل = سعر المتر × (1 + تسوية الوقت + التمويل + ظروف السوق)
السعر بعد التسويات      = السعر السابق × (1 + المساحة + الموقع + الشوارع + الطبوغرافيا + الشكل + الوصول)
سعر المتر المرجّح        = مجموع (سعر كل مقارن بعد التسويات × وزنه النسبي)
قيمة الأرض              = سعر المتر المرجّح × مساحة الأرض
قيمة المباني            = مساحة المباني × سعر المتر
الإهلاك                 = (العمر الفعال ÷ العمر الافتراضي) × قيمة المباني
القيمة السوقية          = (المباني − الإهلاك) + قيمة الأرض + العمارة العظم [+ الأسوار اختياريًا]
النطاق السعري           = القيمة السوقية × 1.15  و  × 0.85
```

**تم التحقق:** إدخال أرقام ملف المقيّم الأصلي يُخرج ‎1,976,237.68 ريال — مطابقة تامة لكل قيمة وسيطة.
